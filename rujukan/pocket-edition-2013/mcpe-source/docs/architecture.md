# Architecture Notes

This folder is for original technical notes and clean-room implementation planning.

Suggested milestones:

1. Define platform and build targets.
2. Implement a small deterministic game loop.
3. Add input abstraction and timing.
4. Add a minimal chunk/world data model using original code and assets.
5. Add rendering behind a platform-independent interface.

Do not copy proprietary or leaked source code or assets into this project. Use independently written code and assets with documented rights.
